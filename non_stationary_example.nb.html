Example of non-stationary BPOT

The estimation of bivariate extreme models can be achieved with two modeling approach: - Global approach - Marginal approach

The global appraoch estimates the all parameters in one go with the censor likelihood. The marginal approach estimates the marginal parameters first, then use it to transform the sample to frechet-distributed margin, then estimates the dependence parameter. The two approaches produce different dependence parameters due to the difference in estimation method, see the following example:

dat <- read_excel("data/FULL_DATASET_1985.xlsx")%>% mutate(is.group = ifelse(N>0, 1,0))

Global approach, non-stationary model

The bulit-in fbvpot method in evd package does not support non-stationary input in the scale parameter, a wrapper function is required for global censored likelihood estimation. These functions are contained in another script.

We start with the non-stationary model with two covariates in T2 (v_conflict, movement type) and one covariate in maxDV (movement type). The function output is a S4 object where common methods like confint, plot can be used.

marginal approach, non-stationary models

First, we need to transform the samples to uniform distribution using the fitted margins, then apply a copula to estimate the dependence parameter. Since the estimation is done separately, the confidence intervals are constructed separately as well. The CI for depdence parameter is a bit weird, I recommend we go with the global approach.
