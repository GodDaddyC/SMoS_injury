Demostration of computing injury probability

Using bivariate POT methods

First we fit a bivariate POT model using the evd package. The thresholds are chosen according to the bvtcplot function

We also check if the thresholds gives a good fit in the margin

then we check the asymptotic tail dependence via the chi and chi2 plots.

Then we can execute the BPOT block in execution.Rmd to estimate the BPOT models. After the estimation, we perform the model diagnostic. Since we have already check the margins, it is enough to check the depedence structure.

The computing probability part is done in execution.Rmd, check it out.

Using copula

First we identify the conditional marginal distribution \(P(X\leq 0|X\leq u)\) using univariate EVT.

Then we need to fitting the conditional marginal distribution of speed, the histogram suggests gamma distribution suits.

Then we need to motivate which copula model to use. Firstly, we check the contour plot of the sample and the contour plot of different theoretical models. The one that best reflects the dependence structure of the sample will be used. Check scripts/Copula_select.R for more details.

We fit the data to Gumbel, Clayton and Tawn T1 copulas, run execution.Rmd for different results.
